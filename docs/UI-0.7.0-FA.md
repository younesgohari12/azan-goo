# YAgent AI 0.7.0-beta.1

این نسخه رابط فارسی فایل ارسالی را به هستهٔ واقعی نسخهٔ 0.6.0-beta.1 متصل می‌کند. صفحهٔ اصلی از دادهٔ نمایشی استفاده نمی‌کند و برای اجرا به Node.js، نصب پکیج یا CDN نیاز ندارد.

## نصب و به‌روزرسانی

1. در پیشخوان وردپرس به «افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه» بروید و `yagent-ai-0.7.0-beta.1.zip` را انتخاب کنید.
2. اگر نسخهٔ قبلی نصب است، گزینهٔ جایگزینی نسخهٔ موجود را انتخاب کنید. افزونهٔ قبلی را از طریق «حذف» پاک نکنید؛ فایل uninstall آن داده‌های YAgent را حذف می‌کند.
3. منوی «YAgent AI ← گفتگو» محیط جدید را باز می‌کند. «تنظیمات و مدیریت» اتصال سرویس، مدل، مجوز ابزارها، سیاست مصرف و ابزارهای تخصصی قبلی را در اختیار شما می‌گذارد.
4. برای سایت جدید، تنظیمات سرویس و کلید خود را ذخیره کنید. سپس در محیط گفتگو «تازه‌سازی وضعیت» را بزنید. کلید API در رابط گفتگو قرار نمی‌گیرد.

نیازمندی‌ها: وردپرس 6.6 به بالا، PHP 8.1 به بالا و مرورگر امروزی با پشتیبانی JavaScript modules. نصب شبکه‌ای وردپرس مطابق نسخهٔ پایه پشتیبانی نمی‌شود.

## کار با رابط جدید

- تاریخچهٔ واقعی گفتگوها، جستجو، تغییر نام، سنجاق و حذف در ستون راست قرار دارد. سنجاق‌ها برای همین سایت و کاربر در همان مرورگر نگهداری می‌شوند.
- «گفتگوی جدید» فوراً یک پیش‌نویس محلی باز می‌کند. رکورد گفتگو هنگام ارسال اولین پیام ساخته می‌شود.
- پیش‌نویس پیام، شناسهٔ درخواست ناموفق و پیوست آماده در نشست همین مرورگر حفظ می‌شوند. فایل ابتدا خصوصی بارگذاری می‌شود و با ارسال پیام به مدل فرستاده می‌شود. پیوست ناموفق قابل ارسال نیست.
- انتخاب «گفتگو» برای پاسخ متنی و «اجرای ابزار» برای مدل تنظیم‌شده با پشتیبانی ابزار است. کنترل «فقط خواندنی» مجوز همین کار را محدود می‌کند؛ مجوز سراسری در تنظیمات اتصال تعیین می‌شود.
- Enter پیام را ارسال و Shift+Enter خط جدید ایجاد می‌کند. کارت‌های پیشنهاد، متن را برای ویرایش وارد کادر می‌کنند.
- مراحل کار، خروجی ابزار، رسید، خطا، کارت تأیید و لینک واقعی ویرایش محتوا نمایش داده می‌شوند. دانلود بستهٔ افزونه از همان API احراز هویت‌شده انجام می‌شود.
- بازکردن دوبارهٔ صفحه، کار ناتمام را اجرا نمی‌کند. «ادامهٔ کار» اجرای آن را ادامه می‌دهد و «توقف» لغو کار را به سرور اعلام می‌کند.
- تغییرات حساس، جزئیات تغییر و محتوای پیشنهادی را پیش از تصمیم نشان می‌دهند. نصب خودکار افزونه‌های تولیدشده همچنان تابع مجوز قبلیِ تنظیمات است.

## پیش‌نمایش و بازخورد

پیش‌نمایش برای پیشنهادهای HTML ابزارهای مدیریت محتوا ساخته می‌شود. می‌توانید عرض دسکتاپ، تبلت یا موبایل را ببینید، روی بخش‌ها علامت بگذارید و توضیح را برای دستیار ارسال کنید. یادداشت‌ها در نشست مرورگر حفظ می‌شوند و متن بازخورد پس از ارسال در تاریخچهٔ واقعی گفتگو ذخیره می‌شود.

این نمایش، محتوای پیشنهادی عملیات است. قالب وردپرس، ابزارک‌های المنتور، شورت‌کدها، منابع خارجی و رندر کامل سایت را بازسازی نمی‌کند؛ برای نتیجهٔ نهایی از لینک واقعی ویرایش یا مشاهده در وردپرس استفاده کنید. انتشار برگه از درخواست در گفتگو و کارت تأیید سرور انجام می‌شود. پیش‌نمایش از مبدأ پیشخوان جداست و اجازهٔ خواندن محتوای والد، ارسال فرم یا درخواست شبکهٔ JavaScript ندارد.

## تغییرات فنی و منابع

- هستهٔ PHP، ذخیره‌سازی، سیاست مصرف و سرویس‌های مدل نسخهٔ پایه حفظ شده‌اند؛ صفحهٔ گفتگو و اتصال رابط جدید اضافه شده است.
- CSS رابط در iframe جدا قرار دارد تا بر استایل پیشخوان و دیگر افزونه‌ها اثر نگذارد.
- REST client از nonce وردپرس، مسیر معمول و `rest_route`، خطای نشست منقضی و شناسهٔ درخواست برای جلوگیری از ایجاد دوبارهٔ کار پشتیبانی می‌کند.
- سورس رابط در `assets/workspace/js/`، استایل‌ها و فونت محلی در همان پوشه، و آزمون‌های Node در `tests/` قرار دارند. `npm test` فقط آزمون‌ها را اجرا می‌کند و نصب وابستگی لازم ندارد.
- آیکن‌های Lucide، فونت Vazirmatn و ابزارهای Markdown موجود در UI ارسالی با اعلان‌ها و مجوزهای همراه نگه داشته شده‌اند؛ رجوع کنید به `THIRD-PARTY-NOTICES.md` و `LICENSES/`.
- [احراز هویت REST وردپرس](https://developer.wordpress.org/rest-api/using-the-rest-api/authentication/)
- [بارگذاری اسکریپت در وردپرس](https://developer.wordpress.org/reference/functions/wp_enqueue_script/)
- محیط آزمون از [WordPress SQLite Database Integration](https://github.com/WordPress/sqlite-database-integration) استفاده می‌کند؛ این ابزار و سرویس AI آزمایشی داخل ZIP محصول قرار ندارند.

گزارش آزمون این انتشار در `QA-0.7.0.md` است. اسناد نسخه‌های قبلی برای سابقهٔ هسته حفظ شده‌اند.
