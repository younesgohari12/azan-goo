# گزارش آزمون YAgent AI 0.7.0-beta.1

تاریخ: 2026-10-23

این گزارش مربوط به نسخهٔ UI جدید است. گزارش‌های قدیمی‌تر پوشهٔ docs سابقهٔ نسخهٔ پایه‌اند.

## محیط و نتیجه

- نصب و فعال‌سازی در وردپرس محلی 7.1.3، PHP 8.4.27 و SQLite Database Integration انجام شد.
- رابط با Chrome در حالت headless، پیشخوان دسکتاپ و عرض موبایل 390 و 550 پیکسل بررسی شد.
- ۱۰ آزمون Node، ۱۱ بررسی جریان اصلی، ۸ بررسی خطا و بازیابی و یک بررسی ذخیرهٔ بازخورد بصری موفق بودند.
- همهٔ فایل‌های PHP و JavaScript بسته از بررسی نحوی عبور کردند.
- در آزمون‌های جریان اصلی و بازیابی، خطای JavaScript ثبت نشد.

## مسیرهای بررسی‌شده

اتصال تنظیمات از فرم اصلی به REST واقعی وردپرس؛ ارسال و ذخیرهٔ گفتگو؛ بارگذاری خصوصی multipart و ارسال پیوست؛ کارت تأیید با جزئیات تغییر؛ اجرای ایجاد برگه پس از تأیید و ادامهٔ خودکار همان کار؛ نمایش HTML پیشنهادی؛ ثبت و ارسال یادداشت بصری در تاریخچهٔ واقعی؛ ساخت و دانلود ZIP از API احراز هویت‌شده.

حفظ پیش‌نویس پس از بارگذاری مجدد؛ جلوگیری از ارسال پیوست نامعتبر؛ حفظ متن و شناسهٔ درخواست پس از قطع ارتباط؛ اجرای نشدن کار ناتمام هنگام بازکردن صفحه؛ ادامهٔ صریح؛ لغو کار متوقف‌شده و آزادشدن گفتگو؛ باز و بسته‌شدن تاریخچه با Escape در موبایل؛ نبود سرریز افقی در عرض 390 پیکسل.

آزمون‌های واحد همچنین مسیر rest_route، nonce منقضی و تازه‌شده، نبود تکرار خودکار POST، بازیابی پاسخ نامطمئن با شناسهٔ درخواست، قفل دوبارکلیک تأیید، نمایش خطای ابزار، حفظ نسخهٔ جدید تأیید در برابر پاسخ دیررس تاریخچه و نمایش خوانای بازخورد را بررسی می‌کنند.

## جداسازی پیش‌نمایش

محدودیت sandbox پیش از اتصال iframe به DOM اعمال می‌شود. آزمون مرورگر تأیید کرد که مبدأ پیش‌نمایش opaque است و خواندن document والد خطای SecurityError می‌دهد. پل postMessage و ایجاد یادداشت با رویداد واقعی موس در قاب تغییرمقیاس‌یافته بررسی شد. CSP درخواست شبکهٔ JavaScript، فرم و base دلخواه را محدود می‌کند.

## محدودهٔ این تأیید

پاسخ مدل در محیط آزمایش با fixture محلی شبیه‌سازی شد؛ هیچ کلید واقعی، حساب پولی یا سایت کاربر استفاده نشد. فایل fixture، وردپرس آزمایش و داده‌های آن داخل ZIP محصول نیستند. اتصال زندهٔ Gemini، GapGPT، AvalAI و آروان‌کلاد، MySQL، تمام ترکیب‌های قالب/افزونه و رندر کامل المنتور در این محیط آزموده نشده‌اند. نیازمندی پایهٔ افزونه PHP 8.1 و وردپرس 6.6 حفظ شده؛ اجرای این گزارش روی PHP 8.4.27 و وردپرس 7.1.3 بوده است.

آزمون‌های Node همراه سورس در tests/rest-adapter.test.mjs هستند و با npm test اجرا می‌شوند. رابط برای کارکرد به نصب Node یا اجرای build نیاز ندارد. تصاویر همراه، محیط آزمایش را نشان می‌دهند.
